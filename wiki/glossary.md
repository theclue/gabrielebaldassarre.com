# Glossary

> Project-specific terminology. Auto-generated by wiki-indexer.

Terms are sorted case-insensitively, ignoring surrounding code formatting. This is a **leaf reference**: the See Also column contains plain source paths, not links back to content pages. Content pages link to this whole page without term anchors. This wiki glossary is distinct from the site's editorial `_data/glossary.yml` and generated in-memory terms dictionary.

| Term | Definition | See Also |
|------|-----------|----------|
| `3d_model` | Post frontmatter describing a CAD asset's presentation, canonical source reference, exports, previews, and print metadata; it is not a CAD release verdict. | `frontmatter-schema.yml`; `_layouts/asset-3d.html` |
| `_computation` | Frontmatter inserted after R knitting with running R version, heuristically detected packages/data sources, timestamp, and graphics device; not a complete reproducibility record. | `R/build_one.R` |
| A01–A20 | Fixed approved article IDs in the current twenty-article extraction corpus; callers cannot replace them with arbitrary paths. | `docs/corpus.yaml` |
| APC | Prefix for rhetorical pattern candidates; retained v0.6 sources use forms such as `APC::R0001`. These are version-local group IDs, not permanent author traits. | `_scripts/author-extraction/rhetorical.mjs`; `docs/author-identifiers.md` |
| Blueprint | A CAD preview rendering treatment and background composition, not a dimensioned engineering drawing or geometric acceptance result. | `_scripts/cad/preview.py`; `_scripts/cad/build.py` |
| `broadcast.sent` | Marker written when at least one Buffer draft succeeds and all counted attempted targets succeed. Skipped channels need not block it; it does not confirm public social publication. | `_scripts/broadcast.py` |
| C01 | The model's scientific-explanation contextual profile; activated by a declared scientific explainer, with individual rules still limited to applicable conditions. | `_scripts/author-extraction/author-model.composition.json`; `_scripts/author-extraction/runtime.mjs` |
| Canonical JSON | Contract-defined deterministic serialization that recursively sorts object keys, preserves array order, and uses compact JSON. | Cloudinary | External image transformation/delivery service referenced through generated fetch URLs and Liquid helpers; emitting a tag does not itself upload an image. | `_plugins/cloudinary_url.rb`; `_plugins/cloudinary_transform.rb` |
| `completed_review_hash` | SHA-256 of the canonical completed review including decisions, notes, applicability, revisions, and merges. Downstream composition calls this identity `source_review_hash`. | `_scripts/author-extraction/review.mjs` |
| Context injection | Session hooks append verified author-runtime instructions to host-assembled context. Hook execution is not proof of provider delivery, model attention, or prose compliance. | `_scripts/author-extraction/post-authoring-plugin.mjs` |
| Create-only | Persistence that creates absent files, can reuse identical artifacts where allowed, and rejects conflicting existing bytes rather than overwriting them. It does not imply promotion or publication. | `_scripts/author-extraction/model-agent.mjs`; `_scripts/author-extraction/compile-author-runtime.mjs`; `Rakefile` |
| D01 | Optional transition-question device whose following passage actually addresses the question; availability is not an obligation to include it. | `_scripts/author-extraction/author-model.composition.json` |
| D1 | Cloudflare's managed SQL database consumed by the SEO tooling through HTTP clients; not a repository-owned application server. | `_scripts/seo/d1.py`; `seo-schema.sql` |
| Decisional dimension | Article-local choices, priorities, and tradeoffs proposed for analysis, then separately reviewed for applicability; mechanical acceptance does not establish an author policy. | `_scripts/author-extraction/patterns.v0.6.schema.json`; `_scripts/author-extraction/review.mjs` |
| Device | Selectively usable explanatory operation, identified by D01–D06. Runtime statuses distinguish `available`, `preferred`, and an explicit eligible task requirement. | `_scripts/author-extraction/author-runtime-profile.schema.json` |
| Direct dependency | Package or tool declared by its consumer's manifest or installation recipe, as distinct from dependencies brought in by that dependency. | `Gemfile`; `_scripts/author-extraction/package.json`; `requirements-seo.txt` |
| DPC | Prefix for decisional pattern candidates, such as `DPC:A0001`; A/E/T identify author-candidate, editorial-format, and thematic classifications within the versioned contract. | `_scripts/author-extraction/decisional.mjs` |
| EPC | Prefix for epistemic pattern candidates, such as `EPC:A0001`; classification and numbering identify review candidates, not automatic approvals. | `_scripts/author-extraction/epistemic.mjs` |
| Epistemic dimension | How a source handles knowledge claims, assumptions, uncertainty, qualification, and informative limits; observations and generalized formulations require separate review. | `_scripts/author-extraction/extraction.v1.3.schema.json`; `_scripts/author-extraction/epistemic.mjs` |
| ETL | Extract, transform, load: here, reading archived audit JSON from R2, normalizing metrics, and inserting rows and processing markers into D1. | `_scripts/seo/etl.py` |
| Flesch–Vacca | Italian readability formula using word/sentence counts and estimated syllables. The legacy plugin's vowel heuristic and labels are not validated comprehension or educational requirements. | `_plugins/readability.rb` |
| Frontmatter | YAML metadata between opening and closing `---` delimiters in a content file. Its fields drive publishing and editorial processing; descriptive schemas are not complete enforcement. | `frontmatter-schema.yml`; `_plugins/validate.rb` |
| G01 | Guardrail requiring contextual selection rather than checklists, fixed placement, or rhetorical quotas. Applicable projected guardrails are mandatory in runtime instructions. | `_scripts/author-extraction/author-model.composition.json`; `_scripts/author-extraction/runtime-guardrails.mjs` |
| Gate C | Explicit user gate following successful external CAD release; it precedes separately consented site packaging and is not supplied by a preview or exporter exit code. | `.opencode/commands/create-cad.md`; `.opencode/agents/cad-site-packager.md` |
| Governed model | Current author-model artifact whose exact bytes are pinned by runtime policy. A separately persisted candidate does not replace it; its compiled synthesis is not separately human-reviewed. | `docs/author-pattern-results/v1.3/author-model.json`; `_scripts/author-extraction/runtime.mjs` |
| Guardrail | A limitation on applying model principles and devices. Runtime compilation projects applicable clauses with lineage; these clauses take precedence over devices and are not optional. | `_scripts/author-extraction/runtime-guardrails.mjs` |
| GULPEASE | Italian lexical readability index based on letters, words, and sentences. Its computed score and historical school/age lookup labels do not establish reader ability or cognitive difficulty. | `_plugins/readability.rb`; `_plugins/difficulty.rb` |
| Hash | Cryptographic digest, usually SHA-256 here, identifying specified bytes or a specified canonical structure. Matching hashes establish that binding, not truth, consent, comprehension, or release authority. | `_scripts/author-extraction/core.mjs`; `_scripts/author-extraction/review.mjs` |
| `incubator` | Collector branch assembling `work/*` contributions into a reviewable PR targeting `main`; collection does not auto-merge or retract external Buffer drafts. | `.github/workflows/collect-incubator-pr.yml` |
| Input hash | Stage-specific `input_hash` binding prepared source/method inputs or verified projections. Recomputed mismatch rejects stale submissions; the hash does not uniquely determine a candidate interpretation. | `_scripts/author-extraction/core.mjs`; `_scripts/author-extraction/consolidator.mjs`; `_scripts/author-extraction/model-agent.mjs` |
| Jekyll | Ruby static-site generator that transforms content, Liquid layouts, configuration, and prepared assets into `_site/`; its development server is separate from production delivery. | `_config.yml`; `Gemfile`; `Makefile.common` |
| JSON Lines (JSONL) | Newline-delimited UTF-8 JSON framing: one request or response per line in the Wikidata Ruby process's stdin/stdout protocol. | `_scripts/wikidata-oracle.rb`; `_scripts/wikidata-integration/index.mjs` |
| JSON-LD | JSON serialization for linked data used in conditional structured-data blocks. Emitting JSON-LD does not itself verify semantic truth or vocabulary conformance. | `_includes/seo.html`; `metadata-schema.jsonld` |
| Knitting | Executing R Markdown chunks with knitr to produce Markdown and figures. It is explicit preprocessing, not an automatic consequence of every site build. | `R/build_one.R`; `Makefile.common` |
| Liquid | Template language used by Jekyll layouts, includes, filters, and custom tags; it also appears in generated Markdown image markup. | `_layouts/post.html`; `_plugins/cloudinary_url.rb` |
| `LOCAL_ONLY` | Finalizer reason for moving a group supported by fewer than two distinct articles into unclustered coverage. Human review can still explicitly approve locally supported source groups. | `_scripts/author-extraction/consolidator.mjs`; `_scripts/author-extraction/review.mjs` |
| Lockfile | Resolved dependency snapshot, including transitive packages, meaningful within its consuming package manager and installation flow. The author-extraction package's Bun lock is not an npm lock for `npm ci`. | `_scripts/author-extraction/bun.lock`; `_scripts/wikidata-integration/package-lock.json`; `renv.lock` |
| Mermaid | Text-based diagram renderer integrated through authored browser initialization and a vendored runtime. Current initialization uses `securityLevel: 'loose'`, not a sanitizer guarantee. | `assets/js/mermaid-init.js`; `_layouts/default.html` |
| Observation | Bounded article-local candidate proposition with a dimension and literal passage evidence. Core-assigned IDs and `unreviewed` status do not certify entailment or author distinctiveness. | `_scripts/author-extraction/extraction.v1.3.schema.json`; `_scripts/author-extraction/core.mjs` |
| Oracle | Consultive evidence/validation tool with a bounded assurance contract. The Wikidata oracle is implemented and read-only; the proposed production `readability_analyze` oracle is not delivered. | `_scripts/wikidata-oracle.rb`; `docs/authoring-oracles.md` |
| Overlay | Foreground presentation image; CAD packaging creates a transparent solid-model PNG, distinct from its blueprint previews, mesh exports, and release evidence. | `_scripts/cad/build.py`; `_plugins/cloudinary_transform.rb` |
| P0001 | First passage ID assigned within an article by raw blank-line segmentation, with Unicode code-point offsets. A passage is a literal citation span, not a semantic paragraph or observation. | `_scripts/author-extraction/core.mjs` |
| P01 | First operational principle: orient exposition and practical adequacy to the actual purpose without turning project sufficiency into arbitrary scientific tolerance. | `_scripts/author-extraction/author-model.composition.json` |
| Post URN | SEO identity in the form `urn:post:<normalized-category>/<slug>`, derived from content paths. Path/category changes can change identity; it is not the public URL. | `_scripts/seo/posts.py` |
| Principle | One of P01–P06, compactly coordinating approved nonsemantic patterns. Every approved author source has exactly one primary principle owner. | `_scripts/author-extraction/model.mjs`; `_scripts/author-extraction/author-model.composition.json` |
| Processing-eligible | Verified operational extraction state permitting consolidation, based on a matching complete host whole-article receipt. It is not exhaustive cognitive coverage or human review. | `_scripts/author-extraction/core.mjs`; `_scripts/author-extraction/consolidator.mjs` |
| Profile | Contextual selection of model principles, rules, and eligible devices, identified by C01–C04. Activating a profile does not activate every contained rule. | `_scripts/author-extraction/runtime.mjs` |
| QID | Wikidata entity identifier such as `Q3353120`, distinct from opaque run-scoped candidate and evidence IDs. A matching candidate is not an approved identity judgment. | `_scripts/wikidata-oracle.rb` |
| R2 | Cloudflare object storage used for raw audit, post-history, Trends, and Search Console JSON. Prefixes have different timestamping and replacement policies. | `_scripts/seo/r2.py`; `_scripts/seo/monitor.py` |
| renv | R project environment manager with a recorded package snapshot. This checkout activates it interactively when available; batch Docker rendering does not restore that lock automatically. | `.Rprofile`; `renv.lock`; `containers/knitr/Dockerfile` |
| `review_source_hash` | Frozen review-input binding over sources, schemas, corpus, and method, before completed human decisions. It is not `completed_review_hash` or downstream `source_review_hash`. | `_scripts/author-extraction/review.mjs` |
| Rhetorical dimension | Source-grounded organization, explanation, and reader-oriented operations. Consolidation keeps pattern scope separate from candidate author relevance; recurrence alone is not distinctive style. | `_scripts/author-extraction/patterns.v0.6.schema.json`; `_scripts/author-extraction/rhetorical.mjs` |
| Runtime manifest | Artifact ledger recording exact profile/instruction paths and hashes, versions, counts, and guardrail resolution. Payload hashes reside here rather than inside the payloads they hash. | `_scripts/author-extraction/compile-author-runtime.mjs` |
| S01 | Optional conceptual context for bounded invariance, derived from retained `SPC::C0001`. It is not a style rule, metaphor requirement, or reason to introduce an unrelated topic. | `_scripts/author-extraction/author-model.composition.json`; `_scripts/author-extraction/runtime.mjs` |
| `sameAs` | Editorial strict-identity annotation, commonly a canonical Wikidata URL. Retrieval and provenance checks do not certify identity truth; preserved existing values remain uncertified. | `_scripts/wikidata-oracle.rb`; `_scripts/semantic-analysis-prompt.md` |
| SDK | Software development kit; the local JavaScript integrations pin `@opencode/plugin` 2.0.24. That package pin does not identify installed host versions or selected AI providers. | `_scripts/author-extraction/package.json`; `_scripts/wikidata-integration/package.json` |
| Semantic dimension | Recurring concepts and relations in corpus subject matter, reviewed separately as conceptual context. Semantic recurrence is not automatically an author trait or a style instruction. | `_scripts/author-extraction/semantic.mjs`; `_scripts/author-extraction/review.mjs` |
| Slug | Lowercase kebab-case identifier used for article filenames, normalized paths, and CAD assets. Governed post preparation requires an explicit validated slug; Rake does not derive it. | `Rakefile`; `_scripts/author-extraction/post-authoring.mjs` |
| Source index | The model's `source_index` ledger preserving each approved source's lineage, support, applicability, and review pointers. It is not a second list of 29 independent writing rules. | `docs/author-pattern-results/v1.3/author-model.json`; `_scripts/author-extraction/model.mjs` |
| `source_review_hash` | Downstream name for the canonical completed-review identity used by model composition and provenance, not the similarly named frozen-input `review_source_hash`. | `_scripts/author-extraction/model.mjs`; `_scripts/author-extraction/model-agent.mjs` |
| SPC | Prefix for semantic concept/relation candidates; retained v0.6 IDs include `SPC::C0001` and `SPC::R0001`. Retention supplies bounded conceptual context, not operative author style. | `_scripts/author-extraction/semantic.mjs`; `docs/author-identifiers.md` |
| `termsdictionary` | In-memory `site.data.termsdictionary` assembled from prerequisites and the static glossary. Occurrence counts can exceed unique post counts; SEO still consumes `site.data.glossary`. | `_plugins/difficulty.rb`; `_includes/seo.html` |
| Transitive dependency | Package introduced through another dependency's requirements rather than directly declared by the project consumer. Its presence alone does not prove active service/provider use. | `_scripts/author-extraction/bun.lock`; `_scripts/wikidata-integration/package-lock.json` |
| WDQS | Wikidata Query Service, consumed for bounded SPARQL graph expansion using an allowlisted direct-property projection; graph hops are not editorial prerequisite depth. | `_scripts/wikidata-oracle.rb` |
| Whole-article receipt | Host-generated session/article/input-hash bookkeeping showing a successful prepared whole-article protocol. | `work/*` | Contribution branches collected into `incubator`; the broadcast path uses `work/broadcast/*` for proposed frontmatter changes. A branch proposal is separate from already-created external drafts. | `.github/workflows/broadcast-social.yml`; `.github/workflows/collect-incubator-pr.yml` |
