## A small Z shell session

Z shell (zsh) is a Unix shell: it reads commands and runs them. This short exercise assumes that the reader already uses Z shell and focuses on repeating a command, not on installing or learning the shell.

Run this command in Z shell and check that the message appears:

```zsh
print 'The command ran successfully'
```

## Optional background

A Unix shell is a command interpreter used on Unix-like systems. Knowing this broader category adds context, but the command above is sufficient to complete the exercise.

POSIX is a family of standards for compatibility between operating systems. POSIX is mentioned only as optional historical background; no knowledge of the standard is necessary to understand or repeat this exercise.
